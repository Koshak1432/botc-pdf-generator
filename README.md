# Генератор памяток BOTC на TypeScript

Самостоятельный CLI-генератор памяток для «Крови на Часовой башне». Он читает JSON сценария, подставляет локализованные названия и описания ролей из каталога, сортирует роли по SAO и печатает HTML/CSS в PDF через Chromium. После страницы для игроков он добавляет лист ночного порядка со сглазами сценария.

## Установка

Требуются Node.js 20.11+ и npm.

```powershell
cd C:\botc-pdf-generator
npm.cmd install
npm.cmd run install:browser
npm.cmd run check
```

Если PowerShell блокирует `npm.ps1`, запускайте именно `npm.cmd`.

## Готовый русский пример

```powershell
npm.cmd run generate -- `
  examples\a-grimm-chorus.json `
  --out output\pdf\A-Grimm-Chorus-ru.pdf `
  --html tmp\pdfs\A-Grimm-Chorus-ru.html
```

Пример берёт роли из единого статического каталога: в нём 181 официальная роль с русскими названиями и описаниями. Все 25 ролей A Grimm Chorus помещаются на первом белом листе A4: секции идут сверху вниз, а роли внутри каждой секции распределяются по двум колонкам в SAO-порядке. Второй лист содержит первую и последующие ночи, а также только те сглазы, обе роли которых входят в сценарий. Рекомендованные Странники автоматически не добавляются.

## Единый русский каталог

Готовый файл `catalog/roles.ru.json` используется локально: обычная генерация PDF не обращается ни к вики, ни к переводчику. В исходном порядке сохранены все 181 роли и технические поля официального `roles.json`, поле `flavor` удалено. В `translations.ru` находятся русские `name`, форматированная `ability`, название команды, ночные подсказки и надписи жетонов напоминаний.

Английские `id`, `team`, `edition`, `special` и канонические `name`/`ability` намеренно сохранены как машинные данные. Это нужно для совместимости и неизменного SAO-порядка; в русской памятке они не отображаются.

Перевод уже выполнен. Необязательная maintenance-команда нужна только при обновлении официального списка ролей:

```powershell
npm.cmd run catalog:ru -- `
  --source "C:\Users\sadri\Desktop\roles.json"
```

Для обычных сценариев указывать каталог не нужно. Другой набор ролей можно передать через `--catalog`. Русский перевод роли хранится рядом с каноническими английскими данными:

```json
{
  "id": "general",
  "name": "General",
  "team": "townsfolk",
  "edition": "carousel",
  "ability": "Each night, ...",
  "translations": {
    "ru": {
      "name": "Генерал",
      "ability": "[b]Каждую ночь:[/b] ..."
    }
  }
}
```

Канонический английский текст используется только для SAO. Перевод и форматирование порядок ролей не меняют.

## CLI

```text
botc-pdf generate <script.json> [--catalog <roles.json>] [options]
```

По умолчанию используются `catalog/roles.ru.json`, bundled-справочники `catalog/nightsheet.json` и `catalog/jinxes.ru.json`, локаль `ru` и максимум 25 ролей на странице. Все эти данные читаются локально; новых параметров для ночной страницы не требуется.

Основные параметры:

- `--catalog <file>` - необязательно переопределить встроенный русский каталог;
- `--out <file>` - путь итогового PDF;
- `--locale <tag>` - локализация из каталога;
- `--overrides <file>` - форматирование и замена изображений;
- `--assets-dir <dir>` - переопределить локальную папку иконок `<role-id>.webp/png/jpg/svg`;
- `--no-fetch-assets` - не скачивать официальные иконки;
- `--html <file>` - сохранить HTML-превью;
- `--memo-json <file>` - сохранить промежуточную модель;
- `--cards-per-page <n>` - изменить пагинацию для нестандартного сценария;
- `--allow-partial` - продолжить при исправимых ошибках входных данных.

## Форматирование текста

Поддерживаются только безопасные теги:

- `[b]...[/b]`;
- `[color=#RRGGBB]...[/color]`.

Пример находится в [examples/formatting.json](examples/formatting.json). Неизвестные конструкции не превращаются в HTML и остаются обычным текстом.

## Иконки

В `assets/roles` находятся все 181 официальная иконка в формате WebP. Эта папка используется CLI по умолчанию, а изображения встраиваются в HTML/PDF как data URI без сетевого запроса. `--assets-dir` позволяет подменить набор локальными файлами. При отсутствии изображения место иконки остаётся пустым: буквенной подложки больше нет.

Проверить или заново загрузить полный набор можно командами:

```powershell
npm.cmd run assets:roles:check
npm.cmd run assets:roles
```

### Автоматический размер иконок на страницах ролей

Названия ролей сохраняют размер 18 pt, описания — 14,5 pt. Иконки по умолчанию имеют размер 19 мм.
Если содержимое страницы не помещается, генератор подбирает наибольший подходящий размер иконок, но не меньше 12 мм.
Одновременно уменьшаются ширина места под иконку и минимальная высота карточки: текст получает больше места без изменения шрифта.
Расчёт выполняется отдельно для каждой страницы ролей после загрузки шрифтов и изображений, в HTML-превью и перед печатью.
Иконки ночного порядка и сглазов сохраняют свои размеры.

Границы задаются в `:root` файла `src/render/print.css`:

```css
--role-icon-size: 19mm;
--role-icon-min-size: 12mm;
```

Минимальный размер должен быть положительным и не превышать исходный.
Если даже минимальные иконки не позволяют вместить текст, PDF не сохраняется; ошибка перечисляет проблемные страницы.
В таком случае уменьшите `--cards-per-page`, чтобы распределить роли по нескольким страницам.
По умолчанию этот параметр равен 25. Автоматический подбор иконок не меняет выбранное количество ролей на странице.

## Правила Бутлегера

Если в сценарии есть роль `bootlegger`, генератор берёт её особые правила из массива `_meta.bootlegger` в JSON сценария.
Каждый пункт выводится отдельным абзацем в исходном порядке и на исходном языке; поддерживаются теги `[b]` и `[color]`.
На ночной странице правила размещаются под заголовком «Бутлегер» над сглазами, а карточка роли убирается со страницы для игроков.
Если Бутлегера нет, его заголовок и отступ не появляются, даже когда `_meta.bootlegger` заполнен.
Если роль есть, но правила не заданы, используется её обычное описание.
При генерации без ночной страницы правила остаются в карточке Бутлегера.

## Таблица количества игроков

Внизу ночного листа автоматически добавляется фотография из `assets/night/player-counts.jpg`.
Она встраивается в HTML и PDF: исходный файл из папки загрузок и доступ к сети не нужны.

Таблица центрируется, сохраняет пропорции и по умолчанию имеет ширину 140 мм.
Если она мешает ночному порядку или сглазам, генератор плавно уменьшает её до максимального безопасного размера.
Учитываются названия, вертикальные обозначения ночей и выступающие за строки изображения, включая закат и рассвет.
Уменьшенная таблица может располагаться между длинными боковыми колонками.
В HTML-превью размер пересчитывается также при изменении содержимого и перед печатью.

Настройки находятся в `.memo-page--night` файла `src/render/print.css`:

```css
--night-table-width: 140mm;
--night-table-min-width: 70mm;
--night-table-bottom: 5mm;
--night-table-gap-mm: 3;
```

Это начальная ширина, минимальная читаемая ширина, отступ снизу и зазор до другого содержимого (последний параметр — число в мм).
Если не помещается даже минимальная ширина, HTML показывает пояснение, а генерация PDF завершается ошибкой.
В таком случае уменьшите размеры ночного порядка или текста сглазов.

## SAO

- порядок команд: Горожане, Изгои, Приспешники, Демоны, Странники, Сказочные, Лорики;
- позиции официального закрепленного каталога остаются опорными;
- homebrew-роли вставляются по группе SAO, длине канонического описания, длине имени, английскому имени и ID;
- для homebrew-роли можно явно указать `saoGroup`;
- перевод и presentation overrides не влияют на сортировку.

## Разработка и проверки

```powershell
npm.cmd run format
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:pdf
npm.cmd run build
```

`npm test` проверяет импорт, локализацию, SAO, безопасное форматирование, ночной порядок, сглазы и HTML-верстку. `npm run test:pdf` запускает настоящий Chromium и проверяет PDF без сети.

```text
src/core/       импорт, каталог, локализация, SAO и модель памятки
src/render/     загрузка иконок, React-шаблон, print CSS и PDF
src/cli/        командная строка
examples/       русский A Grimm Chorus и пример форматирования
tests/          модульные, интеграционные и PDF-тесты
```

Шрифт `Dumbledor 3 Thin` хранится локально, применяется ко всему тексту памятки и встраивается в PDF как подмножество TrueType. Файл шрифта не содержит лицензионных условий; перед публичным или коммерческим распространением генератора необходимо отдельно подтвердить право на распространение самого TTF-файла.

# Генератор памяток BOTC

Из JSON сценария «Крови на Часовой башне» генератор создаёт два PDF: памятку игроков и памятку рассказчика.

Если `BOTC-PDF-Generator.exe` у вас уже есть, откройте его и переходите к шагу 3. Node.js и Chromium включены в файл.

## 1. Установите зависимости

Установите Node.js версии 20.11 или новее. Откройте командную строку Windows в корне репозитория и один раз установите
зависимости для мастера и веб-интерфейса. Исходники и настройки сборки находятся в папке [`project`](project).

```cmd
npm.cmd --prefix project ci
npm.cmd --prefix project run install:browser
```

## 2. Соберите `.exe`

Для сборки нужны Windows x64 с .NET Framework и Node.js x64.
В Проводнике дважды щёлкните по файлу [build-windows.cmd](build-windows.cmd).
Он вызовет встроенный Windows PowerShell 5.1 и оставит окно с результатом.

Готовый файл `BOTC-PDF-Generator.exe` появится в корне проекта рядом с `build-windows.cmd`.
Чтобы пересобрать его после изменений в коде, снова откройте `build-windows.cmd`.

## 3. Получите PDF

1. Запустите `BOTC-PDF-Generator.exe` и выберите один или несколько JSON-файлов. Для выбора нескольких файлов
   удерживайте Ctrl или Shift. Примеры есть в папке [`project/scripts_json`](project/scripts_json).
2. Нажмите «Далее», выберите [`output/pdf`](output/pdf) или другую общую папку и нажмите «Создать PDF».
3. Откройте готовые памятки из последнего окна мастера. Если какой-то сценарий не обработался, там же будет указана причина.

При пакетной генерации, если имя PDF уже занято, мастер добавит один и тот же номер к обеим новым памяткам сценария.

## Веб-интерфейс

После установки зависимостей и Chromium из шага 1 дважды щёлкните по файлу [build-web.cmd](build-web.cmd) в Проводнике.
Скрипт соберёт веб-интерфейс в `project/dist`, запустит сервер и откроет [генератор](http://127.0.0.1:4173) в браузере.
Выберите JSON, нажмите «Создать PDF» и скачайте обе памятки. Чтобы остановить сервер, нажмите Ctrl+C в окне скрипта.

Для запуска из исходников выполните команду из корня репозитория.

```cmd
npm.cmd --prefix project run web
```

Затем откройте [генератор](http://127.0.0.1:4173) в браузере.

## Запуск из терминала

```cmd
npm.cmd --prefix project run generate -- "./scripts_json/teensyville/The-nightmare-king.json"
```

Памятки появятся в [`output/pdf`](output/pdf) в корне репозитория. Путь к входному JSON в этой команде считается
от папки `project`. Справка по параметрам доступна через `npm.cmd --prefix project run generate -- --help`.
